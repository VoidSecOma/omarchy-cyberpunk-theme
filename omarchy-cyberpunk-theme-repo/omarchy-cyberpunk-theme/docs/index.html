Omarchy theme

CYBERPUNK

Neon cyan, hot magenta and electric yellow on void purple. One command, and your whole desktop goes night city.

Install

omarchy-theme-install https://github.com/YOUR_USERNAME/omarchy-cyberpunk-theme

Omarchy clones the repo and applies the theme. Switch back any time with Super + Alt + Space → Style → Theme.

Manual install

git clone https://github.com/YOUR_USERNAME/omarchy-cyberpunk-theme ~/.config/omarchy/themes/cyberpunk
omarchy-theme-set cyberpunk
