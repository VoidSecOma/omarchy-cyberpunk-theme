# Cyberpunk: an Omarchy theme

Neon cyan, hot magenta and electric yellow on a deep void-purple background.

![preview](preview.png)

## Install

```bash
omarchy-theme-install https://github.com/YOUR_USERNAME/omarchy-cyberpunk-theme
```

Omarchy clones the repo, names the theme `cyberpunk` and applies it. To switch to it later:

```bash
omarchy-theme-set cyberpunk
```

Or use the menu: **Super + Alt + Space → Style → Theme**.

### Manual install

```bash
git clone https://github.com/YOUR_USERNAME/omarchy-cyberpunk-theme ~/.config/omarchy/themes/cyberpunk
omarchy-theme-set cyberpunk
```

## What's themed

Alacritty, Kitty, Ghostty, Hyprland borders, Hyprlock, Waybar, Walker, Mako, SwayOSD, btop, Neovim (via [cyberdream.nvim](https://github.com/scottmckendry/cyberdream.nvim)), VS Code (`max-ss.cyberpunk`), Chromium and Yaru-magenta icons. Includes a generated synthwave wallpaper.
